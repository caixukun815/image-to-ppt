# SVG 图标规则

一个完整视觉标记保存为一个 SVG 文件，外部轮廓与内部符号共同缩放。适用于任意外框以及编号、箭头、车辆、人员、灯泡、警示、分享等符号。

图标内部字母、数字、标点转换为路径。不得使用 SVG text/tspan、PPT 文本框、Emoji 或字体图标。卡片和按钮等版式容器不属于图标外框，应与图标分开。

SVG 必须有有效 viewBox；画布默认透明，保留图标本身的填充背景。不得增加用于填满画布的背景色。方形图标本身可以填满 viewBox，不要把合法图标色底误判为多余背景。

不嵌入位图，不使用外部链接、CSS、脚本或字体。使用少量可维护路径与基础几何，保持同组图标的线宽、圆角、留白和视觉重量。复杂滤镜可能影响兼容性，应在实际 PPT 渲染中验证。

优先使用授权且造型准确的矢量资产，否则根据清晰源图重绘。自动描摹只适合信息充足的源图，并需清理噪点和碎片路径。不能以相似库图标替代 Logo 或其他身份关键图形。

运行 `scripts/validate_svg_assets.py svg/`，然后在深浅两种底色上查看图标，并在最终 PPTX 中检查其是否仍为实际引用的 SVG。检查器能发现结构问题，不能自动证明颜色、造型或背景透明区域正确。

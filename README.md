# Image to Editable PPTX · 图片转可编辑 PPT Skill

用 ChatGPT 的视觉理解和图像编辑能力，将幻灯片截图、图片版 PPT 或设计页面重建为可修改文字、可调整元素位置的 `.pptx`。

[下载 Skill ZIP](https://raw.githubusercontent.com/caixukun815/image-to-ppt/main/dist/image-to-editable-pptx-v2.0.0.zip) · [查看 Skill 说明](SKILL.md)

**希望把一张图片恢复成能继续修改的 PowerPoint？这个 Skill 会拆分背景、文字、图标和插画，按原布局重新组合。**

项目以接近原页面的视觉还原和可编辑体验为目标。此前部分页面的试用中，用户评价达到了约 **90% 的预期目标效果**。这是针对具体页面的主观验收反馈，不是“90% 元素可编辑”或固定准确率，也不代表每张图片的结果都相同。

## 可以得到什么

- **可直接修改的文字**：标题、正文、页码、标签恢复为原生 PowerPoint 文本框。
- **保持清晰的小图标**：完整功能图标重绘为透明 SVG，放大、缩小后保持清晰。
- **可调整的布局**：面板、人物、车辆、复杂插画等按适当边界拆开，可独立移动、缩放和调整层级。
- **保留原始构图**：依据源图坐标、比例和遮挡关系摆放，并在渲染后回校。
- **干净的底层**：不嵌入原始整页截图；隐藏文字后，不应露出图片中原来的文字。

一个圆形、方形、三角形或其他外框与内部符号组成的图标，会作为整体 SVG 重建。图标内部的数字、字母和符号转成路径，避免字体或 Emoji 改变造型。

## 谁适合使用

适合只有截图、PNG/JPG 页面或图片版幻灯片，需要继续修改文案、调整结构和制作汇报的人。也适合将生成式 AI 设计的图片页面转成可继续编辑的 PPT。

本项目是一套 **Skill 工作流**，需要在支持文件操作、图像编辑、PPTX 构建与渲染的 ChatGPT/Codex 环境中执行。仅在普通聊天中粘贴 SKILL.md，不等于已经安装了相关工具。

## 安装一次，手动调用

将整个项目作为一个 Skill 安装，保留 `SKILL.md`、`agents/`、`references/` 和 `scripts/`。不需要再安装其他图片转 PPT 流程 Skill，不需要修改个人电脑路径。

可以把项目地址交给 Codex：

```text
请将这个 GitHub 项目作为 image-to-editable-pptx Skill 安装。
保留全部脚本与参考文件，保持仅手动调用。
```

或者下载仓库 ZIP 并解压，把包含 `SKILL.md` 的完整文件夹放进自己的 Codex skills 目录。安装后在新任务中显式调用 `$image-to-editable-pptx`。

## 一句话开始转换

上传图片，并输入：

```text
$image-to-editable-pptx
请将附件图片还原为可编辑 PPTX，保留原页面布局和比例。
文字使用原生文本框；完整功能图标重绘为透明 SVG；
背景、人物、车辆和插画分层，可独立移动缩放。
完成后检查底层残字、元素遗漏、图标清晰度和版面位置。
```

多页任务也可以调用同一 Skill，按用户指定的顺序逐页重建。

## 如何判断“可编辑”

| 对象 | 编辑方式 |
|---|---|
| 原生文本 | 修改内容、字体、字号、颜色和位置 |
| 原生形状 | 修改几何、填充、边框和位置 |
| SVG 图标 | 整体移动缩放；内部路径的直接编辑取决于软件 |
| 人物、车辆、复杂插画 | 作为独立透明图片移动、缩放或替换 |
| 复杂背景 | 保留为重建的背景图片，可替换 |

“可编辑 PPT”不意味着照片和复杂插画中的每一笔都变成原生形状。截图无法确定的字体、被遮挡区域和低清晰度内容，也需要视觉核对。

## 自带检查工具

| 脚本 | 用途 |
|---|---|
| `check_inventory.py` | 检查源图尺寸、元素坐标、素材路径和完成状态 |
| `validate_svg_assets.py` | 检查 SVG 内部文字、嵌入位图、外部资源和 viewBox |
| `visual_compare.py` | 生成原图与结果并排图、叠加图、差异图和坐标标注 |
| `verify_pptx_media.py` | 检查原图整页媒体是否被嵌入、SVG 是否实际引用、原生文字是否存在 |

自动检查用于发现结构问题，最终效果仍需对照原图查看。字体可用性、图片清晰度、页面复杂度以及模型能力都会影响结果。

## 运行环境

需要可用的图像查看与编辑能力，以及支持原生文本、SVG 和渲染的 PPTX 构建工具。Skill 不包含模型服务或 PowerPoint 引擎，执行时遵守当前环境的工具与构建要求。图像生成和编辑可能消耗账户额度。

校验脚本使用 Python 3.9 或以上；视觉对比与源图尺寸检查需要 Pillow：

```bash
python3 -m pip install Pillow
```
